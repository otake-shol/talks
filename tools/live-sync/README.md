# live-sync（発表中のページを聴衆のスマホへ同期）

Marp で出力した `deck.html` に、発表者のページ位置を聴衆のスマホへ同期する機能を後付けする。
聴衆はスライドの QR コードを読むだけで、発表中のページへ自動で追従する。

## 仕組み

```
発表者のPC（?live=present）── ページ番号をPOST ──▶ ntfy.sh（pub/sub中継）── SSEで配信 ──▶ 聴衆のスマホ
```

- Marp の HTML は URL の `#番号` でページを切り替える。受け取った番号を `location.hash` に書くだけで同期できる
- 中継は [ntfy.sh](https://ntfy.sh)（登録不要・無料）。サーバーを自前で持たない
- 途中から開いた人にも、直近のページ位置が届く（`since=latest`）
- 聴衆が自分でページを戻すと追従を止め、「発表中のN枚目へ戻る」ボタンを出す
- 2分以上位置が届かなければ「発表中ではない」とみなし、普通のスライドとして見られる

## 使い方

通常は `scripts/publish.sh <slug>` から呼ぶ（ルートの README を参照）。単体で使う場合:

```bash
node tools/live-sync/inject.mjs <deck.html> --url <公開URL> [--out <出力先>] [--strip-notes] [--copy-assets]
```

- 出力の既定はデッキと同じフォルダの `index.html`。QR コードを `qr.svg` としても書き出す
- `--strip-notes` で発表者ノートを除く（公開用）
- `--copy-assets` で HTML が参照している画像だけを出力先へコピーする

当日の操作:

| 誰が | 開くURL | 操作 |
| --- | --- | --- |
| 発表者 | `<公開URL>?live=present`（ノート付きのローカル版でも可） | いつもどおりページを送る。`q` で QR を全画面表示、もう一度 `q` か `Esc` で閉じる |
| 聴衆 | `<公開URL>`（QRから） | 何もしなくてよい |

QR はスライド本文に `![](qr.svg)` のように貼ってもよい。

## 注意

- トピック名（中継のチャンネル名）は HTML に入るため、見た人は誰でも同じトピックに送信できる。
  いたずらで聴衆のページが飛ぶ可能性はあるが、発表者が30秒ごとに位置を送り直すので自然に戻る
- ntfy.sh の無料枠には送信回数の上限がある。10分LTのページ送り程度なら問題ない
- 会場の Wi-Fi が不安定なときに備え、発表者PCはテザリングも用意しておく
